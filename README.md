# ai_results_arts

Арты и ресурсы для игр, сгенерированные кодом (Python + Pillow, без нейросетей).

## Содержимое

### Тюльпан (`tulip/`)
- `tulip/resource_tulip.png` — ресурс 15×15 (RGBA), стебель + два листа + чашечка из трёх лепестков
- `tulip_preview.png` — превью на клетках лугов/леса рядом с ягодным кустом
- `gen_tulip.py` — генератор; палитра взята из цветов игры (ягодный куст)
- `assets/` — референсные тайлы (луга, лес) и ягодный куст для превью

Запуск: `python3 gen_tulip.py` (нужен Pillow: `pip install pillow`)
